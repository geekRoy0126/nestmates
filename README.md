# Nestmates

Fair chores and clear bills for shared apartments. CS6983 Project 3 — Ruoyu Wang & Qingyu Cheng.

See [docs/PRD.md](docs/PRD.md) for the problem, roles, and user stories, and [CLAUDE.md](CLAUDE.md) for how the
project is built with Claude Code.

## Run

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # Vitest unit + property tests
npm run typecheck
npm run lint
```

Requires Node 22+.
