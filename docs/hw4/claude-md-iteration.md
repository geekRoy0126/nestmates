## Permissions (`.claude/settings.json`, committed)

- **allow** — the commands used dozens of times per TDD cycle (tests, typecheck, lint, read-only git, `git add`/`commit`,
  edits under `src/` and `docs/`) so the red-green loop doesn't stop for prompts.
- **ask** — anything that changes dependencies, history, or what leaves the machine: `npm install`, `git push`,
  `git reset`/`rebase`, edits to `package.json` and `.claude/`.
- **deny** — reading `.env*`, force-push, `rm -rf`, `npm publish`, and network fetches via `curl`/`wget`.
- Personal overrides go in `.claude/settings.local.json`, which is git-ignored.
